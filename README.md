# Papa’s 54th Birthday

Unzip the archive and open index.html in a regular browser. Keep the files together. The built site can run offline and has not been published.

The local copy uses the supplied Lovable components, styling, letter, timeline, family photos and couple illustrations. The Memory Room displays only entries with pictures.


To edit the content, see source/src/data/content.ts and source/src/data/memories.ts. To rebuild after edits, run npm install and npm run build from the source folder. Add new images under memories/ and reference them as ./memories/filename.jpg in the catalog.
